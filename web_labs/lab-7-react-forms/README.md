# Лабораторна робота №7 — Робота з формами в React

## Тема

Робота з формами: керовані та некеровані компоненти.

## Мета

Закріпити практичні навички роботи з формами у React, використовуючи `useState`, `useRef`, об'єкт стану та базову валідацію.

## Реалізовано

- керована форма через `useState`;
- некерована форма через `useRef`;
- багатопольова форма з одним об'єктом `formData`;
- валідація полів форми;
- повідомлення про помилки для окремих полів.

## Технології

- React
- JavaScript
- Vite
- useState
- useRef
- CSS

## Запуск

```bash
npm install
```
