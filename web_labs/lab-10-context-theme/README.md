# Лабораторна робота № 10

## Міні-застосунок «Перемикач теми» на Context API

### Мета роботи

Набути практичних навичок роботи з React Context API, створення контексту та провайдера, керування станом, збереження налаштувань у localStorage і застосування тем оформлення.

### Використані технології

- React
- JavaScript
- Vite
- React Context API
- useContext
- useReducer
- useEffect
- useMemo
- useCallback
- localStorage
- CSS Variables

### Реалізований функціонал

1. Створено ThemeContext і ThemeProvider.
2. Реалізовано перемикання між світлою, темною та синьою темами.
3. Додано системний режим оформлення відповідно до налаштувань операційної системи.
4. Реалізовано збереження вибраної теми в localStorage.
5. Створено кастомний хук useTheme() із перевіркою використання поза провайдером.
6. Для керування станом використано useReducer.
7. Оптимізовано функції та значення контексту за допомогою useCallback і useMemo.
8. Реалізовано синхронізацію теми між вкладками браузера через подію storage.
9. Додано попереднє встановлення теми для запобігання її миготінню під час завантаження сторінки.
