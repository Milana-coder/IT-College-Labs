# Todo-додаток на Recoil

## Мета роботи

Закріпити практичні навички роботи з бібліотекою Recoil у React, навчитися керувати глобальним станом за допомогою atom та selector.

## Опис проєкту

Розроблено Todo-додаток для створення та керування списком завдань. Для зберігання глобального стану використовується Recoil.

## Використані технології

- React
- Vite
- JavaScript
- Recoil
- CSS

## Реалізований функціонал

- Додавання нових завдань.
- Позначення завдань як виконаних.
- Підрахунок кількості невиконаних завдань за допомогою selector.
- Видалення окремих завдань.
- Очищення всіх виконаних завдань.

## Структура проєкту

```text
src/
├── components/
│   ├── AddTodo.jsx
│   └── TodoList.jsx
├── App.jsx
├── App.css
├── atoms.js
├── selectors.js
└── main.jsx
```

## Запуск проєкту

```bash
npm install
npm run dev
```

## Результат

Створено інтерактивний Todo-додаток із глобальним керуванням станом через Recoil. Реалізовано додавання, виконання та видалення завдань, а також автоматичний підрахунок невиконаних завдань.
